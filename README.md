# Portafolio de Joana

Sitio estático para GitHub Pages. Archivos: `index.html`, `styles.css`, `script.js`.

## Antes de publicar

1. Copia tu foto de perfil a esta carpeta con el nombre **profile.jpg**. Si no existe, aparecerán las iniciales JC.
2. Revisa el correo de contacto en `index.html`. Busca `id="email"` y sustituye el `mailto:` por tu correo preferido (sin espacios).
3. Revisa los textos sobre los proyectos, fechas y experiencia.
4. Crea un repositorio público en GitHub llamado `joana51.github.io` y sube los archivos directamente a la raíz.
5. En **Settings > Pages**, elige **Deploy from a branch**, rama **main**, carpeta **/(root)**. Tu sitio quedará en `https://joana51.github.io/`.

Si eliges otro nombre de repositorio como `portfolio`, la dirección será `https://joana51.github.io/portfolio/`.
